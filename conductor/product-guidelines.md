# Product Guidelines: AA-Enabled Multichain Wallet Dashboard

## Visual Identity & Aesthetic
- **Minimalist & Clean:** Adhere to a "less is more" philosophy. Use ample whitespace, soft shadows, and rounded corners (border-radius: 12px+). The interface should feel more like a premium fintech app than a traditional crypto-native site.
- **Grayscale/Monochrome Palette:**
  - **Base:** High-contrast backgrounds (Pure White for light mode, Deep Charcoal for dark mode).
  - **Accents:** Use specific colors primarily for brand identity and status (e.g., #627EEA for Ethereum, #9945FF for Solana, #10B981 for Success/Profits).
- **Typography:** Use clean, highly legible sans-serif fonts (e.g., Inter, Geist, or SF Pro). Prioritize hierarchy to make complex data scannable.

## Voice and Tone
- **Hybrid Support & Precision:** The interface should speak with the authority of a professional tool but the supportiveness of a mentor.
- **Jargon Management:** Avoid obscure acronyms unless necessary. When used, provide unobtrusive tooltips (e.g., "AA" -> "Account Abstraction allows you to...").
- **Clarity over Cleverness:** Action labels should be literal and unambiguous (e.g., "Confirm Transaction" instead of "Send it!").

## User Experience (UX) Principles
- **Progressive Disclosure:** Show only the most critical information first. Allow users to "drill down" for advanced metrics or transaction details.
- **Zero-Friction Feedback:** Every action must have an immediate visual response (loading skeletons, success toasts, or haptic-like animations).
- **Optimistic UI:** When possible, reflect state changes immediately (like a balance update) while the transaction confirms on-chain.
- **Accessibility First:** Ensure high color contrast and keyboard navigability for all core flows.
